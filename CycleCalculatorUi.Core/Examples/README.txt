Example systems
===============

Every .cycle.json file in this folder (and its subfolders) is listed under
"Open example…" in the editor, by its system name. The list is ordered by file
name, so a number in front of the name sets the order. Any system saved from the
editor can be dropped in here.

The folder ships with the program: it lives in CycleCalculatorUi.Core/Examples in
the source and is copied next to the program on build and publish. Changes to the
copied files are picked up while the program runs. The web host can use another
folder with the "Examples:Directory" setting.
